## 한국어 문장·글꼴 규칙 (AI가 화면 글을 쓰거나 고칠 때 지킬 것)

화면에 나오는 글(제목, 안내, 본문, 이름표, 퀴즈, 연습 문제)은 모두 아래 규칙을 따릅니다. 코드 주석은 예외입니다.

**말투**
- 한 키트 안에서는 말투를 하나로 맞춥니다. A·C 키트는 해요체(“병렬로 대요”, “굴절각이 커져요”), B 키트 본문은 합니다체(“위치는 …입니다”)입니다.
- 제목, 부제, 이름표, 퀴즈 보기는 짧은 명사형이나 ‘-다’로 끝냅니다(“평형 위치에서 두 힘이 같다”, “합성 저항”).
- 학생 눈높이의 쉬운 말로 씁니다. 한 줄 안내는 30자 안팎으로 씁니다.

**문장**
- 번역투를 쓰지 않습니다. “~에 의해”, “~를 가지다”, “~하는 것이다”, “~되어지다”, “~에 있어서”, “행동한다(behave)” 대신 우리말 동사로 바로 씁니다.
  - 나쁨: 두 슬릿은 두 광원처럼 행동해요. → 좋음: 두 슬릿은 똑같이 흔들리는 두 광원과 같아요.
- 문장은 끝까지 씁니다. 화살표(→)나 쌍점으로 문장을 대신하지 않습니다(식과 표 안은 괜찮습니다).
  - 나쁨: 저항이 작아 큰 전류 → 퓨즈가 끊어져요. → 좋음: 저항이 아주 작아서 큰 전류가 흘러 퓨즈가 끊어져요.
- 문법이 맞는지 소리 내어 읽어 봅니다.
  - 나쁨: 곧장 나갔다면의 길이에요. → 좋음: 빛이 곧장 나갔다면 지났을 길이에요.
- 조사를 “은(는)”, “이(가)”처럼 괄호로 두 개 쓰지 않습니다. 숫자·단위 바로 뒤에 조사가 오지 않게 문장을 바꿉니다.
  - 나쁨: 4.2 m은(는) 정답이 아니에요. → 좋음: 정답이 아니에요 (내 답 4.2 m).
- 힌트와 안내에 정답을 미리 쓰지 않습니다. 그림이 보여 주는 것과 글이 어긋나지 않게, 숫자는 모델 파일에서 가져옵니다.

**용어·숫자**
- 교과서 용어와 표준 띄어쓰기를 씁니다: 입사각, 굴절각, 법선, 임계각, 전반사, 보강 간섭, 상쇄 간섭, 합성 저항, 내부 저항, 전류계.
- 숫자와 단위는 띄웁니다(9.42 V, 0.2 s, 220 Ω, 13.66 mA). 각도 °는 붙입니다(41.8°).
- 빼기는 −(U+2212), 곱하기는 ×를 씁니다. 변수는 기울인 라틴 글자(<i>v</i>, <i>y</i>)로 씁니다.

**글꼴·조판 (style.css를 고칠 때)**
- 한글은 기울이지 않습니다. 한글에는 기울임꼴 글자가 없어 브라우저가 억지로 비틉니다. 그래서 `font-synthesis: none`을 두고, 기울임은 라틴 변수에만 씁니다.
- 한글에 자간(`letter-spacing`)을 넓히지 않습니다. 영문 대문자 이름표(BAY 01, QUIZ)에만 씁니다.
- 문장에는 고정폭 글꼴을 쓰지 않습니다(낱말 사이가 너무 벌어집니다). 고정폭은 숫자, 단자 이름, 코드에만 씁니다.
- `word-break: keep-all`로 낱말 중간에서 줄을 바꾸지 않습니다. 문단 줄 간격은 1.5 이상으로 둡니다.
- 글꼴 목록에는 한글 글꼴을 꼭 넣습니다(예: `'JetBrains Mono', 'Pretendard Variable', monospace`).

종이 위 실험대에 부품이 하나씩 떨어져 놓입니다. 그다음 장(챕터)마다 프로브나 전선이 정해진 접점에 닿고, 표시창 값이 바뀝니다.
화면은 시간 `t` 하나로 정해지므로, 되감기·장 건너뛰기·속도 조절이 따로 코드 없이 됩니다.

## 새 실험 만드는 순서 (`lesson.js`)
```js
// 1) 부품 놓기: 연결은 앵커 이름으로, 전기 성질은 부품에 (표시값은 solve()가 회로를 풀어 냄)
export const res = resistor('res', 'bb.h10', 'bb.h14', { ohms: 218.6 });
// 2) 장 표: t0 시작(s) · dur 길이 · dial 다이얼 · at 프로브가 닿는 곳 · target 카메라가 담을 부품 · note 안내 두 줄
{ id: 'ohm', t0: 12.7, dur: 5.5, chip: '저항', dial: 'OHM', at: { r: 'res.2', b: 'res.1' }, target: 'res', note: ['…', '…'] }
// 3) 표시값: lcdFor(s)에서 s.touch(닿았나)이면 solve({ meter: { mode, r, b } }).reading
// 4) 화면 글자: 아래 띠(LAB 번호 · 부품 목록), 조립하는 동안 뜨는 말풍선, 내려앉은 부품의 이름표
export const INFO = { lab: 'LAB 01', kit: '멀티미터 · 9 V 건전지 · …', intro: ['첫 줄', '둘째 줄(주황)'], names: { pila: '건전지 9 V', dmm: ['멀티미터', [150, -20]] } };
```
- 아래 칸 4개: ① 표시창 ② 다이얼과 프로브(기능 칸 · 검정/빨강이 꽂힌 단자와 닿은 앵커) ③ 연결 방법(작은 회로도) ④ 기능(지금 자리 · 지난 장 · 다음 장)
- ③의 회로도는 다이얼로 정해짐: V → 병렬, Ω → 전원 끄기, mA → 직렬. 장 표에 `conn: '잘못 연결'`처럼 적으면 바꿀 수 있음 (`병렬` `전원 끄기` `직렬` `방전 후` `잘못 연결`). 회로도 위 상자 글자는 장의 `label`
- 물체 밑의 남색 그림자는 엔진이 부품 높이로 자동으로 그림 (`part(..., { shadow: false })`로 끔)

### 새 부품 만들기 (`parts.js`에 추가)
```js
export function myPart(id, at) {
  const g = part(id, { at, foot: rect(at[0], at[1], 2, 1), h: 1.5 });   // 발자국·높이 (정렬·그림자·카메라에 쓰임)
  prism(g, rrect(at[0], at[1], 2, 1, 0.2), 0, 1.5, '#7aa0e6');           // 몸체: 바닥 다각형을 z 0→1.5로 세움
  anchor(`${id}.out`, [at[0] + 1, at[1], 1.5], { kind: 'terminal' });   // 접점
  return { draw() { /* 다리·선은 tube(), 글자는 decal() */ } };
}
```
- 얇은 판(위에 다른 것이 얹힘)은 `flat: true`로 둡니다. 항상 먼저 그려집니다.
- 구멍에 꽂히는 다리는 `register(id, 종류, { 다리이름: 구멍 }, { 전기 성질 })`로 등록합니다(`board.js`). 그래야 꽂기 규칙 검사와 회로 풀이에 들어갑니다.

## 꽂기·연결 규칙 (`board.js`가 부품을 놓을 때마다 검사)
| 규칙 | 내용 | 어기면 |
|---|---|---|
| 1 구멍 하나에 다리 하나 | 다리·전선 끝은 빈 구멍·소켓에만 | 콘솔 경고 `[꽂기 규칙]` |
| 2 실제 다리 간격 | 저항 3~8칸 같은 행 · LED 1칸 · 축전기 1~2칸 · 버튼은 가운데 홈을 걸쳐 e·f행 | 경고 + 이유 문장 |
| 3 단락 금지 | 두 다리가 같은 줄(같은 열 a~e 또는 f~j)이면 부품이 건너뛰어짐 | 경고 |
| 4 떠 있는 다리 | 다리가 다른 무엇과도 이어지지 않음 (따로 재려는 부품은 `alone: true`) | `__check()`에 표시 |
| 5 프로브 자리 | 장 표의 `at`은 있는 앵커이고, 그 장에서 다른 다리가 꽂힌 구멍이 아님 (`off`로 뺀 전선은 예외) | `checkContacts(CH)` |
| 6 실제 크기 | 저항 몸통 6.3 × 2.4 mm, 리드는 몸통 끝에서 구멍으로 수직, 듀폰 껍데기 6 mm | 부품 함수가 지킴 |

**표시값은 회로를 풀어서**: `solve({ on, meter })`가 마디 전압·부품 전류·계기 값을 계산합니다.
- 모델: 저항 · 건전지(기전력 + 내부저항 1.5 Ω) · LED(문턱 2.0 V + 직렬 15 Ω) · 축전기(직류에서 끊김) · 버튼 · UNO 핀(켜면 5 V)
- 계기: 전압계 10 MΩ · 전류계 0.5 Ω, 0.4 A 넘으면 퓨즈 끊김 · 저항계·다이오드 시험은 1 mA 시험 전류
- 그래서 거꾸로 대면 음수, 전류계를 병렬로 대면 퓨즈처럼 **실제와 같은 결과**가 저절로 나옵니다.
```js
const R = solve({ on: { w2: false }, meter: { mode: 'A', r: 'bb.g16', b: 'bb.R-17' } });
R.reading   // 0.00294 A  ·  R.parts.r1.Vd → 2.94 V  ·  R.fuse → false
```

## 점검
- 주소에 `?t=9&focus=pila.%2B&zoom=90` 을 붙이면 그 시각, 그 접점을 크게 봅니다. `+`는 `%2B`로 씁니다.
- 콘솔에서 `__anchors('bb.h')` 를 실행하면 앵커 목록이 나옵니다.
- 콘솔에서 `__state(9)` 를 실행하면 그 시각의 장, 표시값, 닿음 여부가 나옵니다.
- 콘솔에서 `__check()` 는 규칙 위반·떠 있는 다리, `__nets()` 는 마디 목록(어느 다리끼리 이어졌나), `__solve({...})` 는 회로 풀이를 보여 줍니다.
- 앞뒤 순서는 엔진이 정합니다.
  - 전선·프로브는 토막마다 깊이를 매기므로 상자 뒤로 지나가면 가려집니다.
  - 표시창 글자는 자기 부품 바로 다음에 그립니다.
